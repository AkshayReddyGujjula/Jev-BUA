# Keyboard shortcut trap

Self-test for keys named in a step: `python scripts/trap_server.py` (port 8791) serves `/keys`, whose
shortcuts have no button and no `aria-keyshortcuts`, so only the key the step names can reach them.

base_url: http://127.0.0.1:8791

## The shortcuts sheet opens with "?"
path: /keys

1. Press "?" to open the keyboard shortcuts.
   - see: Keyboard shortcuts

## The command bar opens with Ctrl+K
path: /keys

1. Open the command bar with Ctrl+K.
   - see: Command bar
