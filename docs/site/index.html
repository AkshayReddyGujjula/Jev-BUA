How it works

1. Steps are goals

“Create a project named Apollo.” Jev, a decision model, picks the next control on the live page in about 0.4 s. No selectors, no screenshots, no code to maintain.

2. The page is the verdict

see:, not see:, url contains:, no page errors are read off the real page. A pass is a fact, never a model’s opinion.

3. Reruns are free

Verified flows are recorded by meaning and replayed with zero model calls. When the app changes, one step is re-decided and the plan heals itself.

Built for your coding agent

One MCP server, one CLI. Your agent writes a spec, calls browser_test, and gets back pass/fail, cost, the failing check and what the page showed. Specs and replay plans live in your repo, so CI reruns cost nothing. Several agents can test at once: each run gets its own browser connections, in a separate automation Chrome that never touches your tabs.

claude mcp add jev -- jev-mcp
